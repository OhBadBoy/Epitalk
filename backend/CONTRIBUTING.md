# Contributing

Contributions welcome. Please open issues or PRs. Follow the standard Git workflow.

For the original EpiTalk feature packages, follow the [official 14-branch allocation](BRANCHES.md) and the [roles and UML mapping](../docs/REPARTITION_ROLES_BRANCHES_UML.md). Branch names use `feat/<scope>-<slug>/<owner>`, with an unaccented owner: `hadrian`, `moise`, `daouda`, or `james`. Keep the official set of 14 feature packages unchanged.
